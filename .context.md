# 🧠 AI SYSTEM INSTRUCTIONS FOR SIP-CORE
1. **Teknoloji:** Rust 1.84+ (Network I/O bağımsız Core Library).
2. **Stateless Tasarım:** Bu kütüphane bir SIP paketinin geçmişini (Call Dialog State) bellekte tutamaz. Yalnızca paket parsing (RFC 3261), builder işlemleri ve SDP manipülasyonu yapar.
3. **Zero-Allocation Kuralı:** Ağ geçidinde milyonlarca paket işlendiği için, gereksiz bellek kopyalamalarından (`.clone()`, `String` allocation) olabildiğince kaçınılmalı, referanslar (`&str`, `&[u8]`) kullanılmalıdır.
4. **Ağ (I/O) Yasağı:** Kütüphane kendi içinde TCP/UDP soket açamaz, dinleyemez. I/O işlemleri bu kütüphaneyi kullanan ana servise aittir.
